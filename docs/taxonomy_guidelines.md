# Campaign Taxonomy Guidelines

## Naming Convention

Platform_Channel_Brand_Region_Market_Objective_Currency_CampaignID

Example:

FB_SOC_Philips_NAM_US_CV_USD_820804315294108

## Region Codes

NAM = North America
EMEA = Europe, Middle East and Africa
APAC = Asia Pacific

## Objectives

AW = Awareness
TR = Traffic
CV = Conversion
LE = Lead Generation
